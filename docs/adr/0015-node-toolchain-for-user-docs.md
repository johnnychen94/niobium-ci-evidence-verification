# ADR-0015: Node.js toolchain for the user documentation site

- **Status:** Accepted
- **Date:** 2026-10-07
- **Amended by:** [ADR-0017](0017-chinese-user-documentation.md) (the language rule `tools/check-docs` applies to the site)

## Context

Niobium needs public user documentation: a tutorial, concepts, how-to guides, reference and a status page, published at `https://niobium-project.dev`. `docs/` is maintainer documentation and stays that way. [ADR-0001](0001-repository-baseline-and-zig-only-toolchain.md) makes Zig the only language toolchain, lists the allowed non-language tools, and expects any use of Node.js to come with a new ADR.

No Zig static site generator offers navigation, full-text search, link validation and accessible themes at a comparable level; writing one would be a product of its own. Astro Starlight provides these and builds plain static files from Markdown.

## Decision

- The user documentation site lives in `apps/user-docs` and is built with Astro Starlight on Node.js. Content is Markdown (`.md`) under `apps/user-docs/src/content/docs`.
- Node.js is allowed only for this site. It is not part of `zig build`, `zig build verify` or any product artifact, and no Zig step invokes it. The site is built and deployed by the GitHub Actions workflow `.github/workflows/user-docs.yml` to GitHub Pages; pull requests that touch the site only build it.
- Supply chain: dependencies are pinned to exact versions in `package.json`, installed from `package-lock.json` with `npm ci`, and kept to Astro, its Sätteri Markdown processor, Starlight, `starlight-links-validator` and `starlight-llms-txt`. The Node.js major version is pinned in `apps/user-docs/.nvmrc`.
- The site is versioned. Each deploy rebuilds every published version into one Pages artifact: `/next/` from `main`, `/vX.Y/` for the newest patch tag `vX.Y.Z` of each minor line whose tree contains `apps/user-docs` (at most 12 lines), and `/latest/` for the newest line. The root redirects to `/latest/`, or to `/next/` before the first release, and serves `versions.json`, which the version switcher reads. Pages keep root-relative links in source; a Markdown plugin adds the version base at build time, so a page is the same file in every version. A tag that fails to build fails the deploy.
- Each version publishes `llms.txt`, `llms-full.txt` and `llms-small.txt` generated by `starlight-llms-txt` from the English pages; the root copies are those of the default version.
- `build.zig.zon` lists the Zig apps individually in `.paths`, so the site is not part of the Zig package.
- Repository tools skip `node_modules`, `dist`, `dist-versions` and `.astro`. `tools/check-docs` checks the site like other docs: English only, allowed URL hosts (in `package-lock.json`, only the `resolved` download URLs), and links. Site pages link to each other by root-relative routes (`/guides/package/`), which check-docs resolves against the content directory, and to repository files by `github.com/niobium-project/niobium/blob/main/<path>` URLs, which check-docs requires to exist. The Astro build fails on broken internal links and anchors.
- The site states what the specifications and the acceptance plan define and links to them; it does not become a second source of truth.

## Consequences

- Contributors who change only Zig code still need only Zig 0.17.0. Editing the site locally needs Node.js; the CI build catches site breakage for everyone else.
- A broken spec link or a renamed spec file fails `zig build check-docs`, so the site cannot silently drift from the repository paths it cites.
- The site adds a second dependency tree (about 290 npm packages) to review on upgrades; it is never shipped to product users.
- Hosting depends on GitHub Pages and the DNS for `niobium-project.dev`.
- Every deploy builds each published version from its tag, so deploy time grows with the number of release lines, and an old tag that no longer builds blocks deploys until it is fixed or falls out of the 12-line window. Old versions keep the text they were released with; a fix to them needs a new patch tag.
