Niobium 是一个独立的开源安装程序框架，由一位维护者利用业余时间维护。维护以尽力而为为原则，项目范围和平台列表保持精简。

## 背景

本项目源于作者在同元（TongYuan）工作时遇到的安装程序需求，涉及内部、实验性和商业产品。Niobium 是一个通用框架，没有针对特定产品的依赖。

Niobium 独立维护，不属于同元的商业产品。同元不对本项目提供直接支持或方向指导。

## 维护策略

- **尽力而为，没有服务等级承诺。** 只有一位维护者，对问题、拉取请求或咨询都不保证响应时间。
- **刻意收窄的范围。** [原则](/zh/#principles)不容商量：对安装脚本、钩子、插件或其他运行时扩展的请求都会被拒绝，无论它们对某个产品多么有用。产品特有的行为应当通过 [App Bootstrap](/zh/concepts/app-bootstrap/) 放在你的应用里。
- **平台少，但要做好。** 精力优先投入一级平台；层级与路线图见[平台支持](/zh/platforms/)。
- **1.0 之前。** 格式和接口仍可能变化。每一次契约变更都会在仓库中作为决策记录下来，每项功能的验证状态见[状态与平台](/zh/status/)。
- **安全问题报告**遵循[安全](/zh/security/)页面上的流程。
- **欢迎贡献**，前提是遵循 [AGENTS.md](https://github.com/niobium-project/niobium/blob/main/AGENTS.md) 中的仓库约定。贡献不保证会被合并，移植到新平台的贡献需要有人持续维护其测试。
